Hand-derived vectors: allocation concatenates two clean one-wire qregs and frees the resulting clean two-wire qreg. views flips bit 0 through a view twice; each region call consumes that view and restores its parent to live, so free succeeds. unclean flips a one-wire qreg once, so free traps with code 4 before consuming it. measurement produces Bell amplitudes at 00 and 11, probabilities 1/2; draws 0.1 and 0.9 select 0 and 3 respectively. measuring (CC, since an R function may call only R functions, §3.1 / SPEC-QUESTIONS 19) wraps that call; bad_uncall must trap 4 because the uncalled CC segment contains a measure frame (§7.4). Reversal restores handle states and wire identities for reversible traces; measurement traces are ineligible.
